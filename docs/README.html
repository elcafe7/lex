Lex CLI

A local-first Bible study terminal for reading, searching, studying, exporting, and source-language work from a fast offline command line.

Current version: 2.6.1

Install

1. Install npm launcher

npm install --global @n8te_/lex-cli

The npm package is a small Node.js launcher. On first run it downloads the latest Lex GitHub release archive, verifies the SHA-256 checksum, creates an isolated Python 3.12+ environment, installs dependencies, and caches the offline app under your user profile.

2. Verify install

lex --version may trigger the first-run download and Python setup. A successful install prints the Lex app version, currently 2.6.1. lex help should open the command map.

lex --version
lex help

3. Try it

lex John 3:16
lex search "kingdom of god"
lex strongs G3056

Full Git install

Use this path for development or local edits. It requires Python 3.12+, a normal POSIX shell, and execute permission for setup.sh.

git clone https://github.com/elcafe7/lex.git
cd lex
./setup.sh

Use the Git install when you are developing Lex or want local file edits to take effect immediately.

Command Map

Each command is local-first and returns a focused terminal panel. Use this map to choose the command by the kind of output you want.

Reading

Open a verse, range, or chapter with nearby context. This is the fastest way to read Scripture from the selected Bible edition.

Expected output: a clean passage panel with the requested reference highlighted in context. 
lex John 3:16
lex read Romans 8
lex --next
lex --prev
lex read all
lex -B lxx Genesis 1:1

Study

Use this when you want the passage plus original-language data, interlinear rows, Strong's/STEPBible notes, topics, and cross-references.

Expected output: verse context followed by Greek/Hebrew source text, transliteration, aligned word rows, lexicon notes, Nave's topics, and TSK links when available. 
lex study John 1:1
lex John 3:16 -i
lex -B kjv Genesis 1:1 -i
lex study Romans 1:1 --no-animate

Search

Find verses by word or phrase. Search matches verse text, supports paging, and can be scoped to books or canon sections.

Expected output: ranked verse hits with snippets, highlighted terms, result counts, Page 1, and next-page/more-per-page footer commands. 
lex search "kingdom of god"
lex search Jeremiah --limit 3
lex search covenant -nt
lex search covenant --page 2 --limit 20

Strong's

Look up Greek or Hebrew Strong's entries, search entries by English gloss, or list verses where an indexed number appears.

Expected output: the Strong's number, lemma, definition, and reverse ESV verse usage for indexed numbers, with paging controls for large result sets. 
lex strongs
lex G3056
lex strongs G3056 --page 2 --limit 25
lex strongs love

Verse Web

Use this for a quick map of cross-reference connections around one verse, ranked by local relevance signals.

Expected output: a center verse with connected references, relevance scores, and short previews. 
lex web John 3:16
lex web Romans 1:1 --limit 8

Nave's Topics

Move between topics and verses. Search a topic directly, or give a verse to see its associated theological topics.

Expected output: topic headings with verse references, or a reverse-topic list for a specific verse. 
lex naves faith
lex topic covenant
lex naves John 3:16

Manuscripts

Compare readings and witnesses for a verse, or inspect a manuscript profile by identifier or common name.

Expected output: reading groups, witness lists, coverage notes, or a manuscript profile summary. 
lex manuscript John 1:1
lex manuscript Isaiah 53:11
lex manuscript P66
lex manuscript 1Qisaa

Creeds

Open the historical document navigator or jump directly to a creed/confession by name.

Expected output: tradition-grouped document lists, section navigation, and bilingual text where available. 
lex creed
lex creeds
lex creed nicene
lex creed westminster confession

Dictionary And Commentary

Use dictionary/encyclopedia lookup for terms, and commentary lookup for verse-level notes.

Expected output: local dictionary/encyclopedia entries or commentary excerpts tied to the requested term or reference. 
lex define grace
lex define heliodorus
lex commentary John 1:1
lex commentary Romans 1:1

Export

Create shareable study packets, read-mode images/slides, verse web documents, or search result exports.

Expected output: an export prompt or a Saved to ... path under ~/Documents/lex_exports. 
lex export "John 3:16"
lex export "John 3:16" --mode read --format png
lex export "Ephesians 1" --mode study --format pdf
lex export "John 3:16" --mode web --format docx

Bible Version And Theme

Choose a default Bible, override the Bible for one command, or force the terminal theme when auto-detection is wrong.

Expected output: a version picker or confirmation message; theme flags change the current and saved display preference. 
lex -v
lex -v kjv
lex -B nasb John 3:16
lex -light
lex -dark
lex -auto

Maintenance

Inspect local command history, move through reading position, refresh runtime data, or show version/source credits.

Expected output: history tables, next/previous passages, data update progress, version text, or source/license credits. 
lex history --limit 10
lex history --clear
lex update
lex --credits
lex --version

Runtime Data

Lex runs from local SQLite and JSON stores after installation. The main bundled data areas are Bible editions, ESV interlinear packets, Strong's and STEPBible lexicons, reverse Strong's usage, Treasury of Scripture Knowledge cross-references, Nave's topics, dictionary/encyclopedia content, places, creeds, Septuagint data, and manuscript shards.

Developer/Data Integrity Verification

For a Git checkout, verify runtime data files against the SHA-256 hashes in manifest.json:

python3 - <<'PY'
import hashlib, json, pathlib, sys
root = pathlib.Path(".")
manifest = json.loads((root / "manifest.json").read_text())
bad = []
for rel, info in manifest["assets"].items():
    path = root / rel
    if not path.exists():
        bad.append(f"missing {rel}")
        continue
    digest = hashlib.sha256(path.read_bytes()).hexdigest()
    if digest != info["hash"]:
        bad.append(f"hash mismatch {rel}")
if bad:
    print("\n".join(bad))
    sys.exit(1)
print(f"Verified {len(manifest['assets'])} runtime assets for Lex {manifest['version']}.")
PY

If you install from a GitHub release archive instead of git clone, verify the archive sidecar before unpacking:

curl -LO https://github.com/elcafe7/lex/releases/download/v2.6.1/lex-v2.6.1.tar.gz
curl -LO https://github.com/elcafe7/lex/releases/download/v2.6.1/lex-v2.6.1.tar.gz.sha256
shasum -a 256 -c lex-v2.6.1.tar.gz.sha256
